# Code Review — Dymon (Discord GPT Bot)

## 🔴 Критические проблемы

- [ ] `main.py` — `sys` не импортирован, но используется в функции `job()` (`sys.executable`, `sys.argv`) — бот упадёт с `NameError` при первом вызове задачи перезапуска
- [ ] `main.py` — `bot.run(DISCORD_TOKEN)` блокирующий вызов; код `schedule.every(6).minutes.do(job)` и цикл `while True` после него **никогда не выполнятся**
- [ ] `requirements.txt` vs `pyproject.toml` — критический конфликт версий: `requirements.txt` указывает `openai==0.28` (старое API), а `pyproject.toml` — `openai = "^1.7.0"` (новое API); код использует стиль `openai.ChatCompletion.create`, который работает только с 0.28, но сломан в 1.x

## 🟡 Серьёзные замечания

- [ ] `main.py` — `openai.api_key` и `openai.organization` устанавливаются внутри обработчика команды при каждом запросе; их нужно задать один раз при старте
- [ ] `keep_alive.py` — `restart_bot()` вызывает `os._exit(0)`, что просто убивает процесс целиком, а не перезапускает его — название функции вводит в заблуждение
- [ ] `keep_alive.py` — `render_template` импортируется из Flask, но нигде не используется
- [ ] `keep_alive.py` — блок `if __name__ == '__main__'` с `schedule` и `while True` никогда не выполняется когда файл импортируется из `main.py` (то есть всегда)
- [ ] Отсутствует обработка ошибок в команде `gpt_command` — если OpenAI API недоступен или вернёт ошибку, бот не отправит никакого ответа пользователю

## 🟢 Замечания по качеству

- [ ] `main.py` + `keep_alive.py` — два конкурирующих механизма перезапуска с разным интервалом (5 и 6 минут) без понятной архитектуры; избыточная и запутанная логика
- [ ] `main.py` — комментарий «перезапуск каждые 1 минут» не соответствует коду (6 минут); аналогично в `keep_alive.py` (5 минут)
- [ ] `pyproject.toml` — author не обновлён: `"Your Name <you@example.com>"`
- [ ] `README.md` — инструкция говорит запускать `dymon.py`, но entrypoint — `main.py`; также содержит незаполненные шаблонные заметки (`ваш_email@example.com`) которые должны быть удалены перед публикацией
