# Dymon

Dymon - это инструмент на Python, предназначенный для поддержания работоспособности веб-приложений, размещенных на платформе Replit. Он обеспечивает автоматическую проверку состояния вашего приложения и его перезапуск в случае необходимости.

## Установка

Для установки Dymon выполните следующие шаги:

1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/laneAlien/Dymon.git
   ```

2. Перейдите в директорию проекта:
   ```bash
   cd Dymon
   ```

3. Установите необходимые зависимости:
   ```bash
   pip install -r requirements.txt
   ```

## Использование

Запустите Dymon с помощью следующей команды:

```bash
python dymon.py
```

Dymon будет автоматически проверять состояние вашего веб-приложения и перезапускать его при необходимости.
